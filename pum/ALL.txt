Notes
─────────────────────────────────────────────────────────────────────────────
Vocab (Brev): /data/vvm33/pum_checkpoints/blocktype/vocab.json
  n_classes=93 (91 scatter palette + water class 91 + grass class 92)
  sid_to_class maps raw uint16 SIDs → 0-based class indices

cam_classes: SMELTED_DATA/<session>/labels/cam_classes/{tick:06d}.npy
  int8 (32,32,32) — 0=air, 1..92=block, -1=OOV (ignore_index in CE)
  Rotation: snap raw yaw to nearest 90° then rotate block grid

Tick NPZ (new Furnace, BLOCKSCOPE_DATA/<session>/labels/tick_NNNNN.npz):
  b: (32,32,32) int32 — localized block SIDs (cam-space, snap_yaw applied)
  m: (32,32,32) uint8 — localized visibility mask (same rotation as b)
  local_yaw: float32 — residual after snapping, for renderer
  inventory, pose: JSON strings

Training: always bash /home/vvm33/blockscope/train.sh with env-var overrides
